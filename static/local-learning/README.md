# Local Learning Data

Place exported files here:

- `questions.json` from Question Library "导出题目"
- `flows.json` from Question Library "导出流程"

`flows.json` uses schema v2:

- `schemaVersion: 2`
- `exportCapabilities` marks supported flow abilities

The mobile learning page loads:

- `/static/local-learning/questions.json`
- `/static/local-learning/flows.json`
